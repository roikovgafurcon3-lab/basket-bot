# 🏀 Basket Bot — Null's Brawl

Telegram-бот с напоминаниями о режиме «Баскет» в Null's Brawl.
Считает ротацию от жёсткой точки отсчёта — 20:00 Europe/Moscow,
поэтому перезапуски ничего не сдвигают.

## Запуск

```bash
pip install -r requirements.txt
python basket_bot.py
```

## Переменные окружения (обязательны)

| Имя       | Значение                          |
|-----------|-----------------------------------|
| BOT_TOKEN | токен от @BotFather               |
| CHAT_ID   | твой ID (узнать у @userinfobot)   |

## Расписание баскета

Каждые 4,5 часа: 00:00, 04:30, 09:00, 13:30, 18:00, 22:30 и далее по кругу.
